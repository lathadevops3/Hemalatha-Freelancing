# Screenshot Capture Instructions

When you have credentials or tools available, replace the placeholder screenshots with real captures.

AWS (Project11)
- Configure AWS credentials (`~/.aws/credentials`) or environment variables.
- Run the demo: `python Project11_AWS_EC2_S3_Automation/main.py --demo`.
- Capture terminal output and the generated `sample_upload.txt` presence.

Docker (Project12)
- Ensure `docker` is installed and running.
- Run `python Project12_Docker_Container_Manager/main.py --demo`.
- Use `docker ps` screenshots showing containers, or the script output.

Kubernetes (Project13)
- Ensure `kubectl` is configured for a cluster.
- Run `python Project13_Kubernetes_Health_Checker/main.py --demo`.
- Capture `kubectl get nodes` and `kubectl get pods --all-namespaces` output.

For each capture:
- Save a PNG to the project `screenshots/` folder (e.g., `screenshots/dashboard.png`).
- Update the project's `README.md` to mention the new screenshot file name.
