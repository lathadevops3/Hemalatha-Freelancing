# File Organizer

## Description
Automatically sorts files into folders based on file type and extension, keeping download folders tidy.

## Real-World Scenario
Use this tool to organize messy download folders by moving documents, images, archives, and media into structured subfolders.

## Features
- Scan a source folder and classify files by extension
- Create target folders for common file types
- Support demo mode with sample files

## Technologies Used
- Python 3
- pathlib
- shutil

## How to Run
```bash
python main.py --demo
```

## Sample Input
Run the script against a download folder or use demo mode to simulate files.

## Sample Output
Files are moved into categorized folders such as Documents, Images, Archives, and Videos.
